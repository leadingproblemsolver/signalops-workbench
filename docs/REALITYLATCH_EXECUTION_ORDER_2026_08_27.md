# RealityLatch execution order

1. Human-review the public-evidence payload and contact eligibility.
2. Allocate one qualified contact/company to one strategy arm only.
3. Deliver value according to the strategy contract.
4. Record the actual result in SignalOps.
5. Do not infer adoption from reply/open/click/meeting.
6. Return the micro-pilot output when a bounded input is supplied.
7. Record correction, pilot use, second use, purchase, rejection, or silence with provenance.
8. Compare the three arms only after a balanced first cohort or explicit falsification.
9. Procedurize the winner only after evidence-bearing outcomes.
