# RealityLatch operator review checklist

Before any external action, the human reviewer must be able to answer **yes** to every applicable item.

- The named public fact is real and attributable.
- The message does not imply access to private workflow information.
- Every operational inference is framed as inference, not fact.
- Rapport is based on a real public contribution, not title/bio flattery.
- The recipient receives value before being asked for meaningful cognitive work, except the bounded micro-pilot where the tiny input is the experiment itself.
- The requested input is the minimum necessary.
- No meeting/demo is requested by default.
- No repeated ask is being sent without new value.
- The artifact has a stable id/version so a later correction/use can be attributed.
- The route is still `human_review`; no autonomous send path exists.

After action, log the real result. Do not upgrade evidence state from optimism or silence.
