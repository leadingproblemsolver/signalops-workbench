# signalops-workbench YAML Specification

The numbered files divide the project into independent review surfaces:

1. identity and direct benefit;
2. problem and value;
3. architecture;
4. state, contracts, and invariants;
5. workflows, interfaces, and repository structure;
6. roadmap, evaluation, and metrics;
7. reliability, security, and operations;
8. employer-facing portfolio signal.

`project.bundle.yaml` is the canonical combined representation.

Every capability is explicitly marked as implemented, partially implemented,
documented, planned, or deferred. Future claims must not be presented as current behavior.
